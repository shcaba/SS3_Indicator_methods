An app that runs abundance and mean-length based indicators for stocks that have SS3 stock assessments, as well as custom indicators. These approaches can be used as either a trigger to prioritize a full stock assessment or could be developed into a managment procedure. These methods are meant to help alleviate resource limitations that prohibit full assessments for all stocks.
An online version of this app is available [here](https://connect.fisheries.noaa.gov/IndicatorMethods/).
